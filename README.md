# Industrial Internship – Assembly and Testing

## 📌 Overview

This repository contains the documentation of my one-month industrial internship at **Popular Systems, Coimbatore**, focused on **Electronics Assembly and Testing**.

The internship provided hands-on exposure to PCB assembly, soldering, testing, troubleshooting, wiring, component handling, and industrial safety practices.

## 🏢 Internship Details

- **Company:** Popular Systems
- **Domain:** Assembly and Testing
- **Duration:** 01 July 2025 – 31 July 2025
- **Role:** Intern
- **Location:** Coimbatore, Tamil Nadu, India
- **Department:** Electronics and Communication Engineering

## 🎯 Objectives

- Gain practical experience in PCB assembly
- Learn manual soldering and wave soldering
- Understand electronic component identification and handling
- Perform functional testing of PCBs
- Learn troubleshooting and fault diagnosis
- Understand ESD and workplace safety practices
- Develop teamwork and industrial communication skills
- Learn documentation and quality-control procedures

## 🔧 Technical Activities

### PCB Assembly
- Identified and organized electronic components
- Worked with resistors, capacitors, diodes, ICs, and connectors
- Performed manual soldering
- Assisted in PCB component mounting
- Followed circuit diagrams and layout instructions
- Learned basic wave soldering techniques

### PCB Testing
- Performed power-on testing
- Checked voltage levels at different circuit nodes
- Conducted continuity testing
- Tested PCB functionality
- Assisted in identifying defective components and incorrect connections

### Troubleshooting & Rework
- Diagnosed PCB faults
- Identified defective components
- Used desoldering tools for component removal
- Replaced faulty components
- Verified PCB operation after rework
